# MYF Galaxy Portfolio V5

Portofolio ini dirombak menjadi konsep **Galaxy / Milky Way Command Center**. Struktur V2 tidak dipertahankan. Section, komposisi, navigasi, kartu, timeline, project layout, dan efek visual dibuat ulang.

## Fitur V5
- Splash screen tata surya dengan 8 planet bergerak.
- Background galaxy dan Milky Way tanpa foto pribadi.
- Planet Saturnus ambient dengan opasitas visual sekitar 50%.
- Navbar floating glassmorphism.
- Mobile navigation.
- Mode visual Light/Dark.
- Hero baru dengan orbit system.
- Profile Command Module.
- Skill Radar / Capability Constellation.
- Mission Log timeline.
- Evidence Archive berbentuk mosaic gallery.
- Lightbox semua foto dengan Previous/Next, keyboard Arrow Left/Right, dan Escape.
- Project layout baru berbentuk Creative Lab.
- 5 kartu project, termasuk 3 placeholder yang bisa Anda isi.
- Contact Console dengan mailto Gmail.
- Scroll reveal animation.
- Star field dan ambient nebula.
- Reduced-motion support.
- Responsive desktop, tablet, dan mobile.

## Bagian yang Anda edit
Buka `index.html`.

Project placeholder:
- `PROJECT 03`
- `PROJECT 04`
- `PROJECT 05`

Cari `data-project-url="GANTI_URL_PROJECT_03"` dan seterusnya, lalu ganti dengan URL project Anda.

Informasi profil, pengalaman, pendidikan, prestasi, dan sosial media juga berada di `index.html` agar mudah diedit.

## File utama
- `index.html` : struktur dan seluruh isi portfolio.
- `mldta.css` : seluruh desain V5, responsive layout, animasi, dan visual galaxy.
- `mldta.js` : splash, stars, navbar, reveal, lightbox, theme switch, project guard, dan contact mailto.

Tidak membutuhkan framework atau instalasi package. Cukup buka `index.html` di browser atau upload seluruh folder ke hosting.
